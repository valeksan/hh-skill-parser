# Промежуточный DA-срез — 2026-07-31

## Scope и безопасность

Срез построен по 999 latest snapshot с effective relevance `relevant`.
Версионируются только агрегированные DA-артефакты: частоты, временные ряды,
совместная встречаемость и графики. Здесь намеренно нет SQLite-базы, CSV с
карточками вакансий, описаний, raw HTML/JSON, ссылок, контактов, работодателей
или точных адресов.

## Первичные наблюдения

- «Воинский учёт» встречается в 294 уникальных вакансиях (29,4% корпуса).
- Далее следуют «бронирование граждан, пребывающих в запасе» — 56 (5,6%) и
  «взаимодействие с военным комиссариатом» — 40 (4,0%).
- Наиболее частая пара навыков: «воинский учёт» и взаимодействие с военным
  комиссариатом — 36 уникальных вакансий.
- Временной ряд охватывает 2026-06-30—2026-07-30: 997 из 999 публикаций
  приходятся на июль. Это характеристика текущего двухмесячного scope сбора,
  а не доказательство долгосрочного роста спроса.
- HTML-источник не предоставил структурированные зарплату, опыт, формат
  работы, идентификаторы работодателя и нормализованную географию. Поэтому
  salary/employment-таблицы документируют пропуски, а не позволяют делать
  содержательные сравнения.

## Артефакты

- [top_skills.png](top_skills.png) — частота навыков по уникальным вакансиям.
- [publications_by_date.png](publications_by_date.png) — дневная частота
  релевантных публикаций в часовом поясе Новосибирска.
- `top_skills_rf.csv` и `topics_skills.csv` — частоты навыков и тематик.
- `skill_cooccurrence.csv` — пары навыков в одной вакансии.
- `publication_trends.csv` — дневной ряд в UTC из DA-витрины.
- `publication_trends_novosibirsk.csv` — безопасный агрегированный ряд,
  лежащий в основе опубликованного графика с датами Новосибирска.
- `missing_data.csv`, `salary.csv`, `employment.csv` — профиль полноты данных.
- `query_noise.csv` — результаты по поисковым контурам; это диагностическая
  таблица, не оценка точности без ручной разметки.

## Воспроизводимость графиков

Скрипты [plot_top_skills.py](../../scripts/plot_top_skills.py) и
[plot_publications_timeline.py](../../scripts/plot_publications_timeline.py)
версионируются отдельно от исходных вакансий и читают только агрегированные CSV
этого каталога. Для перерисовки нужен `matplotlib`:

```bash
python -m pip install matplotlib
python scripts/plot_top_skills.py \
  --input research/2026-07-31/top_skills_rf.csv \
  --output research/2026-07-31/top_skills.png
python scripts/plot_publications_timeline.py \
  --input research/2026-07-31/publication_trends_novosibirsk.csv \
  --output research/2026-07-31/publications_by_date.png \
  --label Новосибирск
```
